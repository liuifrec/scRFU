External container type
-----------------------

.. py:class:: anndata.AnnData

   Container supplied by the external ``anndata`` dependency. See the
   `AnnData API <https://anndata.readthedocs.io/en/stable/generated/anndata.AnnData.html>`_
   for its constructor and semantics. scRFU accepts this type; it does not define it.
