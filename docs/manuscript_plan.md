# Methods-paper plan

## Working title and claim

**scRFU: a scalable framework for longitudinal and single-cell receptor
functional unit analysis**

Working methodological claim: scRFU provides a transferable receptor-state
representation for longitudinal, cross-cohort, and single-cell analysis of
adaptive immune repertoires.

This claim is gated on original-RFU parity, independent TCR cohorts, a registered
held-out cohort, meaningful comparators, and reproducible performance/source
tables. Parity alone is necessary but not sufficient novelty.

## Results structure

1. Canonical receptor inputs, deterministic assignment, provenance, and
   technical fidelity to original RFU.
2. Repeated-measures RFU representations, within/between-donor similarity,
   donor retrieval, and explicit persistence/dynamics descriptions.
3. Frozen-reference cross-cohort coverage, held-out transfer, conventional
   comparators, phenotype coupling, and external antigen evidence.
4. Optional BCR extension only if the separate go/no-go gate passes.

## Cohort boundary

The separately governed deep longitudinal cohort is a repeated-measures methods
demonstration, not definitive population evidence and not a replacement for
independent public validation. No private participant data or results belong in
this repository. Public single-cell and TCR cohorts must be selected and assigned
roles before outcome-driven tuning.

## Journal order

1. Cell Reports Methods
2. PLOS Computational Biology
3. NAR Genomics and Bioinformatics

Positioning and submission gates are maintained separately so the manuscript
does not overstate unvalidated capabilities.
